# B站视频信息卡片（深色模式版）

基于 [iceriny/BiliVideoInfo](https://github.com/iceriny/BiliVideoInfo) 修改的个人版本，版本 **1.1.0**，遵循 MIT 许可证。

鼠标悬停在 B 站视频链接上，会显示视频标题、简介、标签、播放/弹幕/点赞/硬币/收藏/分享数据和发布日期；在视频页左侧提供“分享”按钮，一键复制视频信息与链接。

## 功能

- **悬停预览**：默认悬停 0.5 秒显示卡片，可在扩展设置中调整延迟。
- **发布日期**：读取视频接口中已有的 `data.View.pubdate`，显示为“发布于 YYYY-MM-DD HH:mm”（本地时区、24 小时制）；接口没有返回时显示“发布时间未知”。
- **深色模式**：纯 CSS `prefers-color-scheme` 自动跟随系统，覆盖信息卡片、分享按钮/复制提示、设置页；不新增主题开关，也不新增权限。
- **分享**：点击视频页左侧按钮，复制标题、类型、发布日期、简介、标签、各项数据和链接；计数仍按两列对齐。
- **设置页**：可开关调试模式、调整悬停延迟。

## 安装

本仓库是个人修改版，未上架 Chrome/Edge 商店，请手动加载：

1. 在本仓库点击 **Code → Download ZIP**（如果 Releases 里有压缩包，也可以直接下载）。
2. 解压到一个固定的位置。**解压后文件夹根目录必须直接有 `manifest.json`**。
3. 打开 Chrome 或 Edge：
   - **Chrome**：右上角三点 → 扩展程序 → 管理扩展程序 → 打开“开发者模式” → “加载已解压的扩展程序” → 选择解压后的文件夹。
   - **Edge**：右上角拼图按钮 → 管理扩展 → 打开“开发者模式” → “加载解压缩的扩展” → 选择解压后的文件夹。
4. 打开任意 B 站视频页，悬停视频链接即可预览；点击左侧“分享”按钮复制信息。

## 目录结构

```text
BiliVideoInfo/
├─ manifest.json          # 扩展清单（MV3）
├─ css/                   # 卡片与分享按钮样式
├─ options/               # 设置页 HTML/CSS/JS
├─ scripts/               # 内容脚本与接口逻辑
├─ img/                   # 图标
├─ _locales/              # 语言文件
├─ ignore/                # 原仓库保留的旧代码，不参与运行
├─ Packager.py            # 原作者的打包脚本，不影响安装
├─ packagerInfo.json      # 原作者的打包/更新信息
└─ README.md
```

## 说明

- 深色模式只跟随系统设置，不提供手动切换；系统切换后无需刷新页面。
- 发布日期来自视频详情接口，不额外发送请求；接口缺失或数据异常时统一显示“发布时间未知”。
- 本扩展需要访问 B 站页面和 `api.bilibili.com` 接口；如果接口请求失败，卡片可能无法显示完整信息。
